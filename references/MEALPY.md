# MEALPY — Meta-heuristic Algorithm Library

**Link:** https://github.com/thieu1995/mealpy
**Stars:** 1.2k | **Forks:** 257 | **License:** MIT
**Python:** >=3.8x | **Dependencies:** numpy, scipy, pandas, matplotlib, tqdm

## Deskripsi
World's largest Python library for meta-heuristic optimization algorithms. 233 total algorithms (206 official + 27 developed). Mencakup nature-inspired, bio-inspired, swarm intelligence, evolutionary, dan berbagai algoritma optimasi global.

## Kegunaan Potensial
- Optimasi jadwal & resource allocation
- Travelling Salesman Problem (TSP)
- Feature selection untuk machine learning
- Hyperparameter tuning
- Route optimization
